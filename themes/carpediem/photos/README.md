# Фотографии товаров

Положите снимки по подпапкам, названным слагом товара, и запустите импорт:

```
photos/
  split-camo-thermochromic/01.jpg 02.jpg 03.jpg
  tshirt-bitches-money/01.jpg 02.jpg
```

```bash
npx @wordpress/env run cli -- wp eval-file wp-content/themes/carpediem/tools/import-photos.php
```

Первый файл по алфавиту становится главным фото, остальные попадают в галерею.
Повторный запуск не создаёт дублей: уже загруженные файлы пропускаются.

Формат: JPG, PNG или WebP, вертикальные 3:4 (например 1200×1600), до 1 МБ.
Сама папка в git не попадает — это рабочая зона для исходников.
