# CARPE DIEM 2026 — локальная разработка

WordPress + WooCommerce в Docker через [`@wordpress/env`](https://www.npmjs.com/package/@wordpress/env).
Код в репозитории — только тема `themes/carpediem` (монтируется в `wp-content/themes/carpediem`).

## Запуск

```bash
npx @wordpress/env start
```

Сайт: http://localhost:8888 · Админка: http://localhost:8888/wp-admin (`admin` / `password`)

Другие команды: `stop`, `destroy` (снести БД), `run cli -- wp <команда>` (WP-CLI).

Репозиторий хранит тему и инструменты её настройки. WordPress, база данных и
`wp-content/uploads` в Git не входят: на рабочем сайте их нужно устанавливать или переносить отдельно.

## Управление магазином

После входа открой пункт **CARPE DIEM** в левом меню WordPress. В одном месте собраны:

- обзор новых заказов и быстрые ссылки на товары, остатки, доставку, оплату и промокоды;
- тексты, изображения, подборка товаров и порядок категорий на главной;
- ключевые подписи каталога, карточки товара, корзины и оформления заказа во вкладке **Тексты магазина**;
- контакты, соцсети и короткие условия доставки и возврата;
- памятка по наполнению товаров.

Таблица размеров редактируется в **Товары → Категории**, а оттенки кнопок выбора цвета —
в значениях атрибута **Цвет**. Изменения используют штатные настройки WordPress и сохраняются в БД.

## Развёртывание на обычном хостинге

Нужны PHP 8.0+, MySQL/MariaDB, HTTPS, WordPress и активный WooCommerce. Для нового сайта сначала
создай базу в панели хостинга, установи WordPress и WooCommerce, затем установи тему одним из способов ниже.

### Без SSH: через ZIP

На компьютере собери архив темы:

```bash
git clone https://github.com/Vadim6969/wp-CARPE-DIEM.git
cd wp-CARPE-DIEM
mkdir -p dist
cd themes && zip -qr ../dist/carpediem.zip carpediem -x 'carpediem/photos/*' '*.DS_Store'
```

В WordPress открой **Внешний вид → Темы → Добавить тему → Загрузить тему**, выбери
`dist/carpediem.zip` и активируй CARPE DIEM. Затем открой **Настройки → Постоянные ссылки**,
выбери вариант «Название записи» и один раз сохрани настройки.

Для обновления выполни `git pull`, заново собери ZIP и загрузи его там же. WordPress предложит
заменить установленную версию. Перед заменой сделай резервную копию средствами хостинга.

### С SSH: обновление из Git

Клонируй репозиторий рядом с `public_html`, чтобы папка `.git` не была доступна из интернета:

```bash
cd ~
git clone https://github.com/Vadim6969/wp-CARPE-DIEM.git
cd wp-CARPE-DIEM
bash tools/deploy-theme.sh ~/public_html
```

Если WordPress расположен в другой папке, передай её путь вместо `~/public_html`. После первого
копирования активируй тему в админке. Дальнейшее обновление занимает две команды:

```bash
cd ~/wp-CARPE-DIEM
git pull --ff-only origin main
bash tools/deploy-theme.sh ~/public_html
```

Скрипт синхронизирует только `wp-content/themes/carpediem`. База, заказы, настройки магазина,
медиатека и пользовательские фотографии не меняются. Если на хостинге включён серверный кэш,
очисти его в панели после обновления.

### Перенос готового локального магазина

Чтобы получить не пустую тему, а точную копию текущего магазина с товарами и настройками, перенеси
на хостинг базу данных и `wp-content/uploads` через резервную копию в панели хостинга. После переноса
замени локальный адрес `http://localhost:8888` на рабочий домен средствами хостинга или WP-CLI:

```bash
wp search-replace 'http://localhost:8888' 'https://example.ru' --all-tables --skip-columns=guid --path=~/public_html
wp rewrite flush --hard --path=~/public_html
```

Сначала сделай резервную копию базы и подставь реальный домен и путь WordPress.

## Наполнение с нуля

После `destroy` восстановить магазин можно тремя скриптами (порядок важен):

```bash
npx @wordpress/env run cli -- wp eval-file wp-content/themes/carpediem/tools/setup-store.php
npx @wordpress/env run cli -- wp eval-file wp-content/themes/carpediem/tools/seed-demo.php
npx @wordpress/env run cli -- wp eval-file wp-content/themes/carpediem/tools/seed-content.php
```

- `setup-store.php` — классические корзина и чекаут, зоны доставки, оплата при получении, промокод `CARPE10`, тексты про ПДн, настройки писем.
- `seed-demo.php` — атрибуты и 10 демо-товаров с вариациями и cross-sells.
- `seed-content.php` — тексты служебных страниц.

## Фотографии товаров

Снимки кладутся в `themes/carpediem/photos/<слаг-товара>/01.jpg, 02.jpg …` и загружаются командой:

```bash
npx @wordpress/env run cli -- wp eval-file wp-content/themes/carpediem/tools/import-photos.php
```

Первый файл по алфавиту — главное фото, остальные — галерея. Повторный запуск не плодит дубли.
Обложки категорий проставляются автоматически по первому товару категории (только если обложки ещё нет).

Сейчас там лежат **фирменные заглушки**, а не фотографии: их рисует
`bash themes/carpediem/tools/make-placeholder-photos.sh` (три «кадра» на товар, 900×1200).
Когда придут настоящие снимки — очистить папки, положить файлы, запустить импорт.

## Проверки

```bash
bash themes/carpediem/tools/smoke.sh
npx @wordpress/env run cli -- wp eval-file wp-content/themes/carpediem/tools/check-one-click.php
```

`smoke.sh` обходит ключевые страницы: ждёт 200 (и 404 там, где положено), ловит PHP-ошибки
в разметке и проверяет, что каталог не опустел. Принимает адрес: `bash ... smoke.sh https://example.com`.
`check-one-click.php` — валидация имени, телефона и согласия в заявке «купить в 1 клик».

## Если npx падает с EACCES

В `~/.npm` лежат файлы, принадлежащие root (старый баг npm). Одноразовый фикс (нужен пароль):

```bash
sudo chown -R $(id -u):$(id -g) ~/.npm
```

## Осталось до запуска

1. **Онлайн-оплата** (ЮKassa) — нужны реквизиты юрлица и договор.
2. **SMTP** — в контейнере нет почтового сервера, письма не уходят. На хостинге настроить отправку с домена.
3. **Шрифты** — сейчас с Google CDN, перед запуском положить `.woff2` в `assets/fonts/` (см. `ponytail:` в `functions.php`).
   Если сайт будет за Cloudflare или nginx-прокси, добавить в `wp-config.php`:
   `define( 'CARPEDIEM_TRUST_PROXY', true );` — иначе лимит заявок «в 1 клик» посчитает всех посетителей одним IP.
4. **Аналитика** — Яндекс.Метрика, нужен номер счётчика.
5. **Фото и финальные тексты**, включая юридические (оферта, политика — сейчас черновики).
6. **Хостинг**: перенос, HTTPS, бэкапы, кэш на стороне сервера.
